# 🧺 Laundry Mart - Login Page

A modern, visually appealing, and user-friendly login page built using **HTML5** and **CSS3 Flexbox**. This project features a clean split-screen layout with a vector illustration on one side and an interactive login form on the other.

---

## 🚀 Project Overview

The goal of this project was to design a responsive split-layout login page from scratch without using external CSS frameworks (like Bootstrap) or layout hacks (like manual margins/paddings for centering). 

### ✨ Key Features
* **Split Layout Design:** Equal 50/50 horizontal split between a brand visual panel and a user authentication form.
* **Pure CSS Flexbox:** Utilized modern flexbox properties to center content and control element alignment effortlessly.
* **Interactive UI Elements:** Custom styled input fields with focus states, smooth hover transitions on buttons, and clean typography.
