# 🧺 Laundry Wallah - HTML Project

## 📌 About the Project [🚀 Launch Demo](https://html-task02-pqsaslfd4-mern-stack15.vercel.app/)

Laundry Wallah is a simple laundry service webpage built using HTML.

The webpage provides information about laundry services, displays a price list, and includes a booking form where users can enter their name, email, and phone number.

This project was created as part of my journey to learn HTML and web development through practical projects.

## 🎯 Project Objectives

The main objectives of this project are:

- Understand the basic structure of an HTML document.
- Learn how to organize a webpage into different sections.
- Display text, headings, and images using HTML.
- Create ordered lists and tables.
- Build a simple form with required input fields.
- Understand semantic HTML elements.
- Practice writing clean and readable HTML code.

## ✨ Features

The webpage includes the following sections:

### 1. Header Section
Displays the main heading:

"Welcome to Laundry Wallah"

### 2. About Us Section
Introduces Laundry Wallah and describes its laundry services.

### 3. Laundry Image Section
Displays an image related to laundry using the HTML image element.

### 4. Our Services Section
Lists the laundry services offered:

- Washing and Drying
- Ironing and Folding
- Dry Cleaning
- Stain Removal
- Express Services
- Special Garment Care
- And more...

### 5. Price List Section
Displays laundry services and their prices in a bordered HTML table.

| Service | Price |
|---|---:|
| Washing and Drying | Rs. 15.00 |
| Ironing and Folding | Rs. 5.00 |

### 6. Book Now Section
Contains a booking form with three required fields:

- Name
- Email
- Phone

A submit button is provided to submit the form.

### 7. Footer Section
Displays the contact email address:

info@laundrymart.com


## 📚 HTML Concepts Learned

This project helped me practice the following HTML concepts.

### 1. HTML Document Structure

The basic structure of an HTML document includes:

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<body>`

Example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Laundry Wallah</title>
</head>
<body>
    <h1>Welcome to Laundry Wallah</h1>
</body>
</html>
