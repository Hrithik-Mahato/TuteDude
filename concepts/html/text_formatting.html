1. Why is it called <sup>?
sup is short for superscript. The word has two parts:

    - Super — above or over.
    - Script — writing or text.
A superscript is text that appears smaller and raised above the normal text baseline.

HTML deleted text element

The <del> HTML element represents a range of text that has been deleted from a document. This can be used when rendering "track changes" or source code diff information, for example. The <ins> element can be used for the opposite purpose: to indicate text that has been added to the document. This element is often (but need not be) rendered by applying a strike-through style to the text.
