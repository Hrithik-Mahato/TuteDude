What is the Hierarchy (Precedence)?

When multiple CSS rules target the same element, the browser uses the Cascade to decide which style wins. In terms of sheer location/type hierarchy:
  1. Inline CSS is at the very top. It overrides both internal and external CSS because it sits closest to the element itself.
  2. Internal and External CSS share the same general weight level. Between the two, whichever one is loaded or written last in the HTML document wins (due to the cascade rule of "later rules overwrite earlier ones").
